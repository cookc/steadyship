# Steadyship brand

The mark is a ship on a level horizon, inside a porthole: "Horizon", chosen
20 Oct 2026. Wordmark: Sora Bold, tight tracking.

| File | Use |
|---|---|
| `mark.svg` | Line-art mark, single colour (`currentColor`, navy by default). Icons, dark backgrounds, print. |
| `mark-colour.svg` | Colour mark: navy sky, sea-green water, white ship, a small sun. App icon, home page, light backgrounds. |
| `mark-colour-dark.svg` | The same with a white sky and navy mast, for navy or dark backgrounds, where the navy disc would vanish. |
| `logo.png`, `logo-dark.png` | Lockup (colour mark + wordmark) at 2x on a transparent background, for light and dark pages. |
| `social-preview.png` | 1280×640 for GitHub's repository social preview (Settings → Social preview). |
| `logo.html`, `render.cjs` | Source of the PNGs; rerun `render.cjs` after changing the mark. |

Colours: navy `#11314F`, sea `#1C7C8C`, sun `#F4B942`, white on dark `#FFFFFF`,
muted text `#4A5A6A` on light and `#C6D3DE` on dark.
