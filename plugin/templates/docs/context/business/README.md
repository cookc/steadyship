# Business notes

Put here what Steadyship needs to know about how {{BUSINESS_NAME}} works,
as ordinary Markdown (`.md`) files. Steadyship reads every file in this
folder before it assesses an app, answers a question or asks you anything
before a change. The more that is here, the better its questions.

Good things to put here, one file each or all in one:

- how the work is organised: the stages a job goes through, the steps or
  operations inside each stage, and who does them;
- a glossary: what a "job", "quote", "part" or "customer" means here, and
  any codes or numbering schemes;
- who uses which app, and for what;
- which spreadsheet or file is the master for what (prices, jobs,
  customers, parts), and where it lives on the shared drive;
- rules of thumb that live in people's heads: how long a quote is valid,
  when a job is "done", what gets checked before delivery.

If you already have these as Word documents or PDFs, say "turn the files in
<folder> into business notes" and Steadyship will write them here for you.
Nothing in this folder is sent anywhere; it stays in this repository.
