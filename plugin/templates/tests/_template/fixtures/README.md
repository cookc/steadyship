# Fixtures

Real inputs and the outputs the app produced from them, kept so a change
that alters an output is noticed. A promotion records the prototype's
outputs here first (one JSON file per real input: the input's name, the
settings used, the result), and the rebuilt app must reproduce them except
where a recorded decision changed the behaviour. Keep fixtures small and
free of personal data; a path to a file on the shared drive beats a copy.
